## Capture-safe sample job description

Use this text in the app's job-description field for the sample resume. It is safe demo content, not a real vacancy:

> We are seeking an early-career software engineer to build and test web applications. Requirements include Python, React, REST APIs, SQL, Git, Docker, problem solving, Testing, Agile teamwork, cloud deployment, and Machine Learning. Candidates should communicate technical decisions and explain measurable outcomes from project work.

The app's built-in default job description is also suitable. Do not change the analysis results in editing; show the API-generated outcome for the selected resume and role text.

## Capture and edit

- Record at 1920×1080, 16:9, 30 fps. Capture the app window without browser chrome when possible, but retain enough context to identify the actual product.
- Use a real microphone take or a human-approved narration track; keep speech intelligible and music absent or very low.
- Add accurate subtitles matching `subtitles.srt`; proofread names and numbers against the actual screens.
- Remove long waits, but preserve visible interactions that demonstrate the actual workflow.
- Do not add a hosted URL end card until it has been verified; do not publish video until the owner approves.
